## 🚧 常见卡点速查

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| `set-target esp32p4` 失败 | ESP-IDF 版本太旧 | 升级到 v5.5+ |
| 屏幕不亮但程序在跑 | 背光（前序工程配置是 -1 不受控）/ FPC 没插紧 | 先确认背光是否常亮，再重插 FPC |
| 触摸无坐标 | 没在 `app_main` 开头拉高 GPIO21 | GT911 地址会变成 0x5D；代码有自动探测但要确认 |
| 摄像头出图花屏/黑屏 | SCCB 与触摸抢 I2C / 帧缓冲不足 | 确认用 `touch_get_i2c_bus()`；检查 PSRAM 余量 |
| **WiFi 连上就重启（boot loop）** | SDIO 258 + `RESTART_ON_FAILURE=y` | 改成 `n`；确认 `esp_hosted` 已锁定 `==3.0.9` |
| **SD 卡挂载后 WiFi 崩** | SDMMC Slot0/Slot1 共享时钟分频器 | 保证 SD 先于 WiFi 初始化；加运行时守卫 |
| 中文字体显示成方块 | 字库子集缺字 | 用 fallback 链兜底，或往 `used_chars.txt` 补字后重新生成 |
| 编译报 flash 溢出 | 字体 C 数组入库了 | 确认 `main/fonts/*.c` 没搬、改用 SD BinFont |
| F103 命令行构建失败 | 工具链路径 | 需要 `arm-none-eabi-gcc` + Ninja + CMake（本机 STM32CubeCLT 里有） |

> 💡 **调试第一原则**：先怀疑物理层（线、电、接触、排线），再怀疑配置，最后才怀疑代码逻辑。
> 尤其这个项目有大量继承代码——**出现问题时先问"这是继承来的还是我新写的"**，能省一半时间。
